# По делу | Казахстан — авто-канал

Бот сам проверяет новости, пишет пост-комментарий в твоём стиле через Gemini
и публикует в Telegram-канал @podelukz.

## Что нужно сделать перед запуском

1. **Заполни `style_examples.py`** — вставь туда 10-20 своих реальных сообщений.
   Без этого шага бот будет писать нейтральным языком, не твоим.

2. **Проверь список источников** в `sources.py`. Сейчас рабочие: The Astana Times,
   Time.kz, Liter.kz. Tengrinews/Zakon.kz/Informburo не отдают публичный RSS —
   если найдёшь у них рабочую RSS-ссылку, просто добавь строкой в файл.

3. **Скопируй `.env.example` в `.env`** и впиши туда свои реальные токены
   (они у меня уже есть, просто перенеси в файл на сервере).

## Запуск локально (для проверки)

```bash
pip install -r requirements.txt
export $(cat .env | xargs)   # подтягивает переменные из .env
python main.py
```

Бот будет крутиться бесконечно и проверять новости каждые 20 минут
(можно поменять `POLL_INTERVAL_MINUTES` в `.env`).

## Куда положить, чтобы работало круглосуточно (бесплатно)

Локально на своём компьютере бот работает, только пока комп включён и открыт терминал.
Чтобы канал жил сам по себе — нужен сервер. Бесплатный вариант:

**Render.com (Background Worker, free plan)**
1. Залей этот код в GitHub-репозиторий (можно приватный).
2. На render.com → New → Background Worker → подключи репозиторий.
3. Start command: `python main.py`
4. В Environment добавь переменные из `.env` (Render хранит их отдельно, безопасно).
5. Deploy — всё, бот работает 24/7 бесплатно.

Могу поднять это прямо через подключённый у тебя Render-аккаунт, если скажешь —
не буду создавать сервисы без твоего подтверждения.

## Как это устроено (коротко)

```
main.py          — главный цикл: раз в N минут запускает всё остальное
news_fetcher.py  — читает RSS-ленты, достаёт заголовок/текст/фото
db.py            — SQLite, чтобы одна новость не постилась дважды
generator.py     — отправляет новость в Gemini, получает готовый пост
poster.py        — публикует пост (фото + текст) в Telegram-канал
style_examples.py — твои примеры текста для калибровки стиля (заполни сам)
sources.py       — список RSS-источников
config.py        — читает токены из .env, ничего не хардкодит
```
